# Sketchie GTM Plays

An 11-slide deck of the GTM plays Sketchie runs after the October 19, 2026 launch: the agreed effort-versus-return scores, the four plays, what is parked, the rules, and owners for launch week.

The whole deck is `index.html`. Arrow keys, space, or the buttons move between slides. A link ending in `#s3` opens on slide 3.

## Publish on GitHub Pages

1. Create a new repository, for example `sketchie-gtm-plays`.
2. Upload `index.html`, `.nojekyll` and this `README.md` to the root (Add file > Upload files > Commit changes).
3. Settings > Pages > Source: Deploy from a branch, Branch `main`, folder `/ (root)`. Save.
4. After about a minute the deck is live at `https://<your-username>.github.io/sketchie-gtm-plays/`.

To update, upload a new `index.html` over the old one and commit.

## Before sharing

A GitHub Pages site is public to anyone with the URL, even from a private repository (unless your organization has private Pages). The deck names team members and internal decisions. The `noindex` tag keeps it out of search results but does not hide it.
