How it works

Three moves, about a minute.

1

Give it a source

A prompt, or a document you already wrote. Document mode follows your source instead of inventing a generic script.

2

Watch it draw

Each element draws on stroke by stroke, timed to the word of narration it belongs to. Nothing appears that the narration never mentions.

3

Fix what is wrong

Open the scene, change it, re-render that scene alone. Every edit keeps a version you can revert to.

The science

Timing is not a style choice.

Sketchie publishes the research behind its generator, graded by evidence. These are constraints the output has to satisfy.

12-30sScene length

One idea per scene.

3-7Elements

Counted at the end of the scene.

2-5sReveal spacing

Never two closer than 1.2 seconds.

500msWord sync

Each element lands on its word.

140-160Words per minute

Spoken register, not read.

3 wordsLabel limit

A keyword, never a sentence.

Question

Every video closes by asking the viewer to produce the answer.

Pause

The video holds, so the answer is theirs before it is given.

One line recap

Then the loop closes. The question is never replaced by a summary.

The six minute ceiling comes from engagement research across 6.9 million online learning sessions, a deliberate cap rather than a technical limit. Read the full spec with citations.

Questions

The honest FAQ.

including the one we lose

Can I edit a single scene?

Yes. Scenes are addressable, so an edit targets one of them, that scene re-renders alone, every edit creates a version, and you can revert.

What if the source is too long?

Longer material becomes a chaptered series. Individual videos are set in 30 second increments up to six minutes, or Sketchie picks the length.

How does a video end?

With a retrieval beat: a question, a pause, then a one line recap. The pause is deliberate.

Can I try it without paying?

Two watermarked videos, up to one minute each, no card required, with the editor included rather than held back.

Is Sketchie faster than Simi?

No, and we say so. Simi is faster at first generation. The argument is about the time it takes to reach a video you will actually publish, revisions included.

Can developers drive it?

An API that returns the video with its scene graph, an MCP server so agents can generate and edit, and a CLI. API access starts on Plus.
